# California Science Grade 6 · Science Dispatch 科学阅读与研究报

G6 让学习者像阅读一份研究报道那样进入科学问题：先弄清主张与模型条件，再核对数据能支持什么，还缺少什么。主题从生态系统与食物网，延伸到热与波、太阳能驱动的地球过程、板块运动、河流海岸变化和资源选择。英语目标从 B1+ 支架进入 B2 式证据论证，强调有条件地解释和承认不确定性。

## 取材与创作

以 Macmillan/McGraw-Hill 2008 年版《California Science Grade 6》主教材的七章、28 课为章序，并核对 Interactive Text、Reading and Writing、Activity Lab Book 的配套目录。网页采用原创研究报道、模拟数据、练习与人文情境；扩展阅读连接官方或科研机构资料，不复制教材原页。

## 全册章节

- 第 1 章 地球生态系统｜连接光合作用、微生物、食物链与食物网、能量金字塔和物质循环。
- 第 2 章 地球的陆地与水域｜比较陆地生物群系、水域生态系统与加州生态环境，讨论同一地点的不同使用者。
- 第 3 章 热能｜研究热流、波、燃料和固体与流体中的热传递，比较保温方案与测量条件。
- 第 4 章 地球系统中的能量｜研究电磁波谱、太阳辐射和对流，分清太阳能驱动的过程与例外。
- 第 5 章 板块构造与地球结构｜用板块、地震、火山和加州地质证据理解变化，同时辨别风险图与精确预测。
- 第 6 章 地表塑造｜把天气、风化、侵蚀、河流、海岸与生境变化串成过程链，比较两次输沙模型并解释曲流和三角洲。
- 第 7 章 地球资源｜比较能源来源、可再生与不可再生资源及材料用途，检验使用次数和清洗假设怎样改变结论。

## 学习方式

28 课全部开放。每课有英文研究阅读、图像术语卡、分类或模拟操作、证据判断、句子拼接和约 100–150 词的主张—证据—推理写作，并要求说明模型局限或下一步检验。每章另有一篇原创科学与社会阅读，把生态、风险或资源问题放进公共决策情境。

## 综合复习

课内螺旋回访把旧概念放入新问题；七个章末回顾检查本章证据判断，全册 28 题综合复习检查跨章提取。完成后的回访建议按 1、3、7、30 天逐步拉开间隔，目标是让孩子独立比较数据、保留假设并把解释迁移到新情境。

## 期末检查与学习评估

选择题回顾记录得分并给出证据解释和回课链接；写作由学习者或家长依据主张、证据、推理和局限自行检查，系统不自动给论证质量打分。B2 是课程设计目标，不构成语言能力认证或标准化考试结果。

## 成长模块与家庭学习

亲子独立本地档案保存观察、写作草稿、七篇人文阅读回应、复习时间和测验记录，支持备份迁移。河道调整、地震风险地图、学校保温与资源全生命周期等情境，训练孩子在科学证据之外看见受影响的人、长期成本和未被模型覆盖的因素。

## 培养的能力

重点培养多来源阅读、数据比较、因果链解释、辨认模型假设、评价方案的局限与公平性，以及写出结构完整的英文科学论证。
